Speed Browser Support

Speed Browser can independently accelerate JavaScript timers, animation frames, Web and CSS animations, and audio or video playback. It does not accelerate downloads or network requests. Media speeds depend on webpage and browser support and are capped at 16×.

If a page behaves unexpectedly

  1. Tap the sliders button in the browser toolbar.
  2. Set the affected type to 1×, turn that type off, turn all acceleration off, or disable it for the website.
  3. Reload the page.

To report an issue, visit github.com/jonluca/speed-browser/issues.
