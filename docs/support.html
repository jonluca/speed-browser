Speed Browser Support

Speed Browser accelerates JavaScript timers. It does not accelerate downloads, video, or network requests.

If a page behaves unexpectedly

  1. Tap the sliders button in the browser toolbar.
  2. Set the speed to 1×, turn acceleration off, or disable it for the current website.
  3. Reload the page.

To report an issue, visit github.com/jonluca/speed-browser/issues.
